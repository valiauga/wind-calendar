How it works

Coast and Inland are ready-made calendars covering every spot in that group — one click with Add to Google Calendar if you use Google Calendar (the ICS link works for Apple Calendar, Outlook or anything else). They'll pick up any spots added to that region later automatically, no need to resubscribe.

If you'd rather pick specific spots from either region, use Create your own mix below instead. It can't use the native one-click "Add" button — that only works for a calendar that already exists with fixed content, and Google only offers it for calendars it already hosts. Instead you get a link: Open in Calendar app hands it to whatever your device's default calendar is (on a Mac that's usually Apple Calendar, even if you use Google Calendar day to day — that's an OS-level setting, not something this site controls). To get a custom mix into Google Calendar specifically, use Copy link and paste it into Google Calendar's own Settings → Add calendar → From URL.

That link stays yours: if you come back later and change which spots are checked, the same link keeps working and your calendar app just picks up the new content on its next refresh — no need to remove the old subscription and add a new one. It's tied to this browser, not an account, so a different device or a cleared browser needs its own link.

Events show the spot, forecast peak sustained wind and direction. They carry no attendees, no reminders, and are marked as free time. Forecasts update roughly hourly from GFS model data, with a live correction applied where a nearby KNMI weather station is available. A custom mix (and any ICS link) refreshes roughly once a day, on that app's own schedule, not something this site controls.
